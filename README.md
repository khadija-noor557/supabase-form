# 🎓 Student Management System

A responsive **Student Management System** built with **HTML, CSS, JavaScript, Bootstrap, and Supabase**.
This project allows users to easily add, view, update, and delete student records through a clean and user-friendly interface.

## ✨ Features

* 📝 Add new student records
* 📋 View student data dynamically
* ✏️ Edit existing student records
* 🗑️ Delete student records
* 🗄️ Store data using **Supabase Database**
* ⚡ Dynamic functionality with JavaScript
* 📱 Fully responsive design
* 🎨 Clean and modern Bootstrap UI
* 🔄 Real-time data fetching from the database

## ⚙️ How It Works

1. Enter the student's information in the form.
2. Submit the form to save the data.
3. Student records are stored in the Supabase database.
4. Saved records can be viewed on the student data page.
5. Existing records can be edited or deleted.

## 🎯 Purpose

I built this project to practice **database integration and CRUD operations** while learning how frontend applications can communicate with a backend service using Supabase.
